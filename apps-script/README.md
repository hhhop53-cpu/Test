# Журнал результатов Артёма — настройка

## 1. Создать проект Google Apps Script
1. Открой https://script.google.com/ и нажми «Новый проект».
2. Назови проект «Журнал английских тестов Артёма».
3. В файле Code.gs удали шаблонный код и вставь содержимое файла Code.gs из этой папки репозитория.
4. Нажми «+» рядом с «Файлы», выбери «HTML», назови файл Dashboard (без .html) и вставь содержимое Dashboard.html из этой папки.

## 2. Разрешить создание таблицы
1. В редакторе выбери функцию getResults и нажми «Выполнить».
2. Google попросит разрешения — подтверди их.
3. Скрипт автоматически создаст Google Таблицу «Журнал результатов английских тестов Артёма» при первом запуске.

## 3. Опубликовать веб-приложение
1. Нажми «Развернуть» → «Новое развертывание».
2. Тип: «Веб-приложение».
3. «Выполнять от имени»: Я.
4. «У кого есть доступ»: Все.
5. Нажми «Развернуть» и скопируй URL веб-приложения, заканчивающийся на /exec.

## 4. Подключить тест
1. Открой файл artyom_english_challenge_a2_plus.html в GitHub.
2. Найди строку:
   const RESULTS_ENDPOINT = "PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
3. Замени текст внутри кавычек на URL веб-приложения из шага 3.
4. Сохрани изменение (Commit changes).

После этого Артём проходит тест и нажимает «Отправить результат». Результат сохранится в Google Таблицу, а URL веб-приложения будет отдельной страницей журнала для просмотра всех попыток.

## Важно
- Не публикуй ссылку на журнал в открытом доступе: любой, у кого есть URL веб-приложения с доступом «Все», сможет просматривать журнал.
- Для обновления кода Apps Script после изменений файлов в GitHub нужно вручную скопировать соответствующие изменения в редактор Apps Script.
- Время отправки записывается сервером Google при получении результата.
